Unit 3: Review and Editing

1. Grammar and Syntax

  • Example: Correct “She go to school” → “She goes to school.”
  • Example: Correct “Him is happy” → “He is happy.”

2. Clarity and Conciseness

  • Example: “He ran really fast in order to get there quickly” → “He ran fast to get there.”
  • Example: Replace vague words with precise ones: “big” → “enormous”

3. Paragraph Organization

  • Example: Group all setting details in one paragraph, actions in another, reflections last.
  • Example: Chronological order helps make a narrative easy to follow.

4. Proofreading Techniques

  • Read aloud to catch awkward phrasing. Example: “The dog barked loud and ran quickly” → “The dog barked loudly and ran swiftly.”
  • Check punctuation: “Lets eat grandma!” → “Let’s eat, grandma!”
  • Use checklists: grammar, spelling, vocabulary, sentence length, transitions.

Practice Exercises

  • Edit a short paragraph to improve grammar and clarity.
  • Reorganize sentences in a jumbled story.
  • Identify and replace weak words with stronger vocabulary.
