Unit 2: Data Collection and Storage

Types of Data

  • Structured: Tabular format, easily stored in relational databases (e.g., CSV, SQL).
  • Unstructured: Freeform data like text, images, video, audio (e.g., social media posts, photos).
  • Semi-structured: JSON, XML — data with some organizational properties but no rigid schema.

Data Collection Methods

  • Manual Entry: Google Forms, Excel sheets, surveys.
  • Web Scraping: Using BeautifulSoup, Scrapy, or Selenium to extract data from websites.
  • APIs: Access structured data from platforms like Twitter, weather services, government databases.
  • Sensors and IoT Devices: Automated collection from smartwatches, traffic monitors, thermostats.
  • Transaction Logs: Sales, inventory, and activity records from business operations.

Common Data Sources

  • Open Government Portals: data.gov.in, WHO datasets, UN repositories.
  • Academic Sources: Kaggle, UCI Machine Learning Repository, research papers.
  • Private Sector Data: CRMs, ERP systems, financial databases.

Data Storage Systems

  • Flat Files: .csv, .json, .xml — best for simple, portable storage.
  • Relational Databases (RDBMS): MySQL, PostgreSQL — use SQL to manage structured data.
  • NoSQL Databases: MongoDB, Cassandra — ideal for unstructured or flexible schema data.
  • Data Lakes: Hadoop, Amazon S3 — store vast amounts of raw data in native format.
  • Cloud Storage: Google Drive, OneDrive, Dropbox — offer file storage with online access.

Data Quality and Integrity

  • Accuracy: Correct representation of real-world values.
  • Completeness: No missing values or records.
  • Consistency: No contradictory data across systems.
  • Timeliness: Data should be up-to-date and current.
  • Uniqueness: Avoid duplication of records.

Backup and Security Measures

  • Backups: Automatic or scheduled file and database backups to prevent data loss.
  • Encryption: Secure sensitive data both during transfer and at rest.
  • Authentication: Username/password protection, OTP, biometrics for access control.
  • Audit Trails: Logging of access and changes for traceability.

Popular Tools

  • Data Collection: Google Forms, Typeform, Excel.
  • Scraping: BeautifulSoup, Scrapy, Selenium.
  • Databases: MySQL, PostgreSQL, MongoDB.
  • Cloud Platforms: Google Cloud Storage, AWS S3, Azure.
