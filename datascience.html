Data Science and Computing

This module introduces students to computing, programming, and data science. It provides a foundation in Python, data analysis, Excel, and modern data collection tools for developing problem-solving skills.

📘 Unit 1: Introduction to Data Science 📗 Unit 2: Data Collection and Storage 📙 Unit 3: Python Programming for Data Science 📕 Unit 4: Data Analysis with Pandas and Excel

Module Overview

Unit Topic Focus
Unit 1 Introduction to Data Science Understanding the field and applications
Unit 2 Data Collection and Storage Sources, methods, formats, and databases
Unit 3 Python Programming Basics of Python and its data science use
Unit 4 Data Analysis with Pandas & Excel Hands-on data handling, analysis & visuals
