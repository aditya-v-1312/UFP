Unit 3: Python Programming for Data Science

Overview

Python is a high-level, general-purpose programming language that is simple to learn and powerful in its capabilities. It is widely used in data science due to its rich ecosystem of libraries for computation, visualization, and machine learning.

Why Python for Data Science?

  • Easy-to-understand syntax similar to English.
  • Massive community support and open-source ecosystem.
  • Powerful libraries like NumPy, Pandas, Matplotlib, and Scikit-learn.
  • Great for scripting, automation, web development, and data analysis.

Basic Python Concepts

  • Variables: Store data in memory using syntax like x = 5.
  • Data Types: Integers, floats, strings, booleans, and complex types.
  • Comments: Use # for single-line and '''...''' for multi-line.
  • Indentation: Controls the flow of the program (especially in loops and functions).

Control Flow

  • Conditional Statements: if, elif, else blocks to control decisions.
  • Loops:
    • for loops: Iterate over lists or ranges.
    • while loops: Repeat while a condition is true.

Data Structures

  • Lists: Ordered, mutable collections [1, 2, 3]
  • Tuples: Ordered, immutable collections (1, 2, 3)
  • Dictionaries: Key-value pairs {"name": "Alice"}
  • Sets: Unordered collections with no duplicates {1, 2, 3}

Functions

  • Defining: Use def keyword to define reusable blocks of code.
  • Example:
def greet(name):
    return "Hello " + name

Libraries for Data Science

  • NumPy: Arrays and mathematical operations.
  • Pandas: Data manipulation and analysis (dataframes).
  • Matplotlib / Seaborn: Visualization tools for plotting graphs.
  • Scikit-learn: Machine learning algorithms and utilities.

Working with Files

  • Reading a file: open("data.txt", "r")
  • Reading CSV with Pandas: pd.read_csv("data.csv")
  • Writing to a file: open("output.txt", "w")

Jupyter Notebooks

  • Browser-based interactive environment for writing and running Python code.
  • Supports Markdown, code, and output visualization.
  • Ideal for experimenting with data science code in real time.
