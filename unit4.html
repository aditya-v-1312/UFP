Unit 4: Data Analysis with Pandas and Excel

Introduction to Pandas

  • Installing: pip install pandas
  • Importing: import pandas as pd
  • File Handling: read_csv(), read_excel(), to_csv(), to_excel()
  • Previewing Data: .head(), .tail(), .info(), .describe()

Data Cleaning

  • dropna(): Remove missing values
  • fillna(): Replace missing data
  • drop_duplicates(): Remove duplicate rows
  • astype(): Convert column data types

Data Extraction Techniques

  • df['column'], df[['col1', 'col2']]: Access columns
  • df.loc[rows, cols]: Label-based indexing
  • df.iloc[rows, cols]: Position-based indexing
  • df[df['Age'] > 25]: Boolean filtering

Descriptive Statistics

  • Central Tendency: mean(), median(), mode()
  • Dispersion: std(), var(), min(), max()
  • Correlation: corr(), cov()

Data Visualization with Pandas

  • df.plot(): Line chart
  • df.plot.bar(): Bar chart
  • df.plot.box(): Box plot

Visualization Libraries

  • Matplotlib: Low-level plotting library
  • Seaborn: Built on Matplotlib, great for statistical plots
  • import matplotlib.pyplot as plt
  • import seaborn as sns

Excel Tools for Analysis

  • Data import/export from CSV or XLSX files
  • Sorting, Filtering, Data Validation, Subtotaling
  • Charts: Bar, Line, Pie, Scatter
  • Conditional Formatting for pattern detection

Excel Forecasting Tools

  • Goal Seek: Find input to achieve a target output
  • Scenario Manager: Compare different outcomes
  • Forecast Sheet: Predict future values from data trends
